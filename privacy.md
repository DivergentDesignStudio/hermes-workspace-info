# Privacy policy — Hermes Workspace personal integration

## Operator and scope

This integration is operated for personal use by the owner of the DivergentDesignStudio GitHub account using Hermes Agent. It is not a service open to the public. Questions can be raised at https://github.com/DivergentDesignStudio/hermes-workspace-info/issues. Do not post personal information or credentials in public issues.

## Google data accessed and purposes

After explicit Google OAuth consent, the integration can access Gmail messages and metadata, send or organize mail, manage calendars and events, read and manage Google Drive files, read contacts, and read or edit Google Sheets and Docs. Access is used to perform the account owner's requested assistant tasks, not for advertising or sale of data.

## Processing and sharing

Hermes runs on the owner's computer. Google APIs receive requests needed to carry out tasks. Relevant content selected for an assistant task may be sent to the AI model provider configured in Hermes. That provider's processing, retention and security are governed by the owner's provider settings and applicable provider terms. This integration does not authorize Google user data to be used to train generalized AI or machine-learning models. The owner must use provider settings and terms consistent with that restriction. Data may also be shared with recipients or services when explicitly requested by the owner, such as sending an email or sharing a Drive file.

## Storage, retention and deletion

OAuth credentials are stored in the owner's local Hermes configuration, not in this public repository or website. Task content may be retained in local conversation history, logs, generated files or notes and by the configured model provider according to its settings. There is no claim of zero retention. The owner can delete local records and credentials and use provider controls for any provider-retained records. Revoking Google authorization stops future authorized API access but does not automatically delete previously saved material.

## Security and control

Credentials and saved records should be protected using the computer's access controls and not shared publicly. The owner can revoke access at https://myaccount.google.com/connections at any time. This website contains only information pages; it does not collect Google credentials or Google account content. GitHub operates the hosting platform and may process ordinary website request metadata under its own privacy policy.

## Google API Limited Use

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements: https://developers.google.com/terms/api-services-user-data-policy.

## Changes

This policy is maintained in the public repository. Its commit history records updates. Material changes to the integration's use of data require an updated disclosure and any necessary consent.
